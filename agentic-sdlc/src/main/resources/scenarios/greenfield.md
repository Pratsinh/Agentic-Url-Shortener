Add a link preview capability to the URL shortener: a new read-only endpoint GET /api/v1/links/{code}/preview that returns the link's code, original URL, creation time, expiry time (if any) and whether the link is currently expired, so a client can show where a short link leads before following it. Previewing must not redirect and must not count as a click. Unknown or malformed codes return 404 in the same RFC 7807 problem format as the other endpoints; an expired link still returns its preview with expired=true. The endpoint must be part of the published OpenAPI contract and covered by tests.
